Remote Internship - Frontend

This repository contains a JavaFX-based frontend for the Remote Internship project.

How to run

  1. Install Java 21 (JDK) on your machine.
  2. Build with Maven: mvn -DskipTests package
  3. Run the application via JavaFX plugin or run the produced JAR.
